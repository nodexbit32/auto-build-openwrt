# Auto-build x86 OpenWrt firmware

This repository automates building x86 OpenWrt firmware for four distributions using GitHub Actions.

## Supported distributions
- Official OpenWrt
- Lienol's OpenWrt
- ImmortalWrt
- Lean's OpenWrt (coolsnowwolf/lede)
